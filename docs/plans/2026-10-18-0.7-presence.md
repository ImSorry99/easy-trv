# Easy TRV 0.7 — Presence — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rooms read presence from a global or per-room entity and, while away, are lowered by a number of kelvin or switched off; a new target while away is an override until home.

**Architecture:** The core gets `away` and `away_override` in `RoomState`, `away_action` and `away_setback` in `RoomConfig` and a `PresenceChanged` event. One function `setpoint.target()` gives the value the thermostats should show; every write and comparison of the setpoint uses it. "Off" is a third hold in `setpoint.holding()`, so `core/hold.py` transitions apply unchanged. The HA side resolves the entity per domain and the unknown policy in a `PresenceInput` beside `HoldInputs`.

**Tech Stack:** Python 3.14, Home Assistant custom integration, pytest + pytest-homeassistant-custom-component, ruff, mypy, uv.

**Spec:** `docs/specs/2026-10-18-easy-trv-0.7-presence-design.md`

## Global Constraints

- `core/` imports nothing from `homeassistant`.
- Setting keys: `presence_entity`, `presence` (room only: `global` / `none` / `own`), `presence_unknown` (`away` / `home`, default `away`), `away_action` (`setback` / `off`, default `setback`), `away_setback_kelvin` (0.5–10, step 0.5, default 3.0).
- Lowered target: `clamp(max(wish - setback, min(frost, wish)), setpoint_range)`; never above the wish, never below the frost temperature unless the wish is.
- Presence acts only while the operating mode is heat and `away_override` is false.
- New heating state `setback_away` between `boost` and `frost`; `off_away` (placeholder) becomes live.
- Bus event `easy_trv_away`, data `{"room": <name>, "state": "on" | "off"}`.
- Texts in `strings.json` = `translations/en.json`, and `translations/de.json`; German labels: "Abwesenheit", "Anwesenheits-Entität", "Bei unbekannter Anwesenheit", "Bei Abwesenheit", "Absenkung (K)", states "Abgesenkt: abwesend".
- Gate per task: `uv run pytest -q`, `uv run ruff check .`, `uv run ruff format --check .`, `uv run mypy` clean (the diagnostics socket test fails only in the cloud sandbox).
- Commits: author ImSorry99 noreply; no `Co-Authored-By`, no Claude/AI mention.

## Review Focus

- A sleepy thermostat that still reports the old wish while lowered must get the target again, not be taken as a knob turn (Task 2 test `test_a_stale_wish_while_lowered_is_drift`).
- Presence away while a window is open, then the window closes: the room must stay held (off) or lowered, not heat to the wish (Task 3 test `test_window_closes_during_away_off_room_stays_off`).
- Presence entity removed or renamed in HA: state missing → unknown → policy, no exception (Task 4 test `test_missing_presence_entity_counts_as_unknown`).
- A room set to `own` without an entity must be refused by the form (Task 5 test `test_room_presence_own_needs_an_entity`).
- Override survives a restart but ends when presence reads home after it (Task 4 test `test_override_restored_then_cleared_by_home`).
